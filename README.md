# STELLARE — CHANNEL SELECT (static)

Чистая статика без Svelte, сборщиков и Node.js: только HTML, CSS и JavaScript.
Внешний вид, анимации, эффект воды, клавиатурная навигация и уведомление «скоро»
полностью повторяют исходную Svelte-версию.

## Что внутри

```
index.html      — вся разметка и все ссылки/тексты
styles.css      — все стили (шрифты, адаптив, анимации)
app.js          — вся интерактивность (выбор, hover, ripple, клавиатура)
background.mp4  — фоновое видео
favicon.png     — иконка сайта
fonts/          — шрифты (Rodin Pro, NewRodin Pro, Russo One, IBM Plex Mono)
start.cmd       — локальный запуск на Windows (двойной клик)
serve.ps1       — мини-сервер для start.cmd (на GitHub не нужен)
.nojekyll       — чтобы GitHub Pages не трогал файлы через Jekyll
```

Все пути относительные (`styles.css`, `fonts/...`, `background.mp4`), поэтому сайт
работает и локально, и в любом подкаталоге GitHub Pages.

## Локальный просмотр

Двойной клик по `start.cmd` — откроется `http://127.0.0.1:8767/`.
Node.js не нужен, сервер работает на встроенном PowerShell.

Можно и просто открыть `index.html` в браузере, но при `file://` Chrome и Edge
иногда блокируют загрузку локальных шрифтов, и текст выглядит иначе. Поэтому
для проверки лучше использовать `start.cmd` (или любой другой статический сервер,
например `python -m http.server 8000`).

## Как залить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория
   (index.html должен лежать в корне, а не внутри `site/`).
   Через сайт: **Add file → Upload files** — или через git:

   ```bash
   cd site
   git init
   git add .
   git commit -m "STELLARE channel select"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
   - нажмите **Save**.
5. Через минуту сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

> Если хотите хранить статику в подпапке репозитория, переименуйте `site` в `docs`
> и выберите в настройках Pages папку **/docs**. Больше ничего менять не нужно —
> пути в проекте относительные.

## Как менять контент

Всё редактируется прямо в `index.html`, без сборки.

- **Ссылка пункта** — атрибут `href` у `<a class="entry__hit">`.
- **Название** — текст внутри `<span class="entry__label">`.
- **Подсказка внизу** — атрибут `data-hint` у блока `.entry`.
- **Порядковый номер / слой** — `data-layer` и `--order` в `style`.
- **Наклон, сдвиг, размер** — переменные `--angle`, `--dx`, `--dy`, `--scale`.
- **Бейдж «СКОРО»** — блок `.entry__badge` внутри `.entry__line`.
  Если у пункта нет `href` (как у «Разработки игры»), по клику он показывает
  уведомление и трясётся.
- **Текст уведомления** — функция `renderNotice()` в `app.js`.

## Важно про размер

`background.mp4` весит около 7 МБ — это нормально для GitHub (лимит на файл 100 МБ),
но при частых изменениях видео репозиторий будет расти. Шрифты и видео можно
заменить своими, сохранив имена файлов, — тогда код менять не придётся.
